## Редакция по замечанию владельца

Владелец попросил заменить искусственный учебниковый стиль живым языком выступления.
Все 23 фрагмента переписаны от первого лица с последовательным объяснением:
одна база, проблема нескольких баз, 2PC, маршруты, действия и примеры.
Это по-прежнему реконструкция, а не цитата; оговорки о неполных источниках
вынесены в отдельные абзацы «Примечание к реконструкции». Все восемь переводов
обновлены по новой русской версии, включая переходы и структуру абзацев.

Дополнительно владелец предоставил `gorodid_2024-0.jpg` … `gorodid_2024-4.jpg`.
Вместе с прежним портретом они составляют галерею из шести фото после читалки.
У доклада 2023 года отдельная галерея с `gorodit_2023.jpg`.
Галереи раскрываются нативным `details`, работают без JavaScript; ссылка
рядом с PDF ведёт к галерее. Превью WebP сохраняют весь кадр; новые JPEG
доступны по клику в исходном размере и без изменения содержимого.
Подписи переведены на восемь языков; имена участников групповых фото не выдуманы.

По уточнению владельца фотографии открываются в отдельной модалке: кнопки
влево/вправо, стрелки клавиатуры и клик по самому фото пролистывают галерею.
Просмотр идёт по кругу; в галерее из одного фото переключение отключено.
Escape и кнопка закрытия возвращают фокус к открывшей просмотр миниатюре.
Выбранный слайд и его URL-фрагмент при просмотре фото сохраняются. Фото целиком
вписывается в окно; подпись и счётчик переведены на все восемь языков.
Без JavaScript либо поддержки `dialog.showModal` сохраняется обычная ссылка
на изображение. Локальный preview отдаёт JPEG с `Content-Type: image/jpeg`.

Финальная проверка после редакции и добавления модалок, 2026-10-08:
